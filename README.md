# As Aventuras da Maitê

Site estático com as histórias da Maitê. Todo o conteúdo vem de `historias.md`:
para adicionar/editar histórias, edite esse arquivo (mesmo formato: `## 🍭 Parte N — Nome` para categorias,
`### N. Título` para histórias, `**Fim** 🍫` no final) e faça push. O GitHub Pages publica sozinho.

Testar localmente: `python3 -m http.server 8765` e abrir http://localhost:8765
